# Editing the website

The five main pages use the `academic` layout and the existing GitHub Pages/Jekyll build.

- Content: `_includes/academic-content/` (home, publications, talks, teaching, CV)
- Navigation, metadata, and footer: `_layouts/academic.html`
- Layout and fonts: `assets/css/academic.css`
- Portrait: `images/portrait.jpg`
- Talk slides: `slides/`
- Page URLs and redirects: `_pages/`

Edit the relevant HTML content file to update a page. Publish by committing to the existing `master` branch. The previous theme, old post URLs, and files remain available in the repository.
